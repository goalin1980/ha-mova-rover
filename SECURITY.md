# Security policy

Do not open a public issue containing a MOVAhome password, password hash,
access or refresh token, device ID, UID, serial number, MAC address, QR code,
Wi-Fi details, signed download URL, map or raw cloud response.

For a suspected vulnerability, use GitHub's private **Report a vulnerability**
feature for this repository. Revoke the affected MOVAhome session or device
share immediately if credentials may have been exposed.
